# PAR Digital - Prototipação de Interfaces

## 📌 Sobre o projeto

O PAR Digital é uma proposta de sistema voltada à
digitalização e ao gerenciamento de processos
administrativos.

Este repositório apresenta o trabalho de prototipação
das interfaces do sistema, desenvolvido no Figma.

O objetivo da prototipação é representar visualmente
as funcionalidades e os fluxos de navegação,
contribuindo para a compreensão da solução proposta.

## Prototipação

A prototipação foi realizada utilizando o Figma,
com foco na organização das interfaces e na
representação dos fluxos de interação do usuário.

### Ferramenta utilizada
- Figma
